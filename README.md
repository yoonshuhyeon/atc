# ATC (Auto Talk Card) - 오프라인 술자리 내비게이터 🍻

**ATC**는 오프라인 3:3 또는 4:4 과팅/미팅 현장에서의 어색함을 깨고, 가장 긴장감 넘치는 순간인 **'자리 바꾸기'**를 기술적으로 완벽하게 서포트하는 MVP 서비스입니다.

## 🚀 프로젝트 핵심 가치
틴더가 '만나기 전'을 케어한다면, **ATC는 '만난 후(술자리)'를 케어합니다.** 
눈치 보이는 번호 따기나 어색한 자리 배치를 익명 투표와 스마트 알고리즘으로 해결하여 현장의 텐션을 하드캐리합니다.

## ✨ 주요 기능

### 1. 퀵 룸 입장
- 6자리 룸 코드를 공유하여 팀원들과 즉시 프라이빗 룸 생성 및 입장
- 본인만의 개성 있는 닉네임과 성별 설정

### 2. 비밀 지목 (Secret Pick)
- 상대 팀원 중 마음에 드는 사람을 아무도 모르게 지목
- 내가 누구를 찍었는지는 나에게만 표시되어 익명성 보장
- 이성 팀원만 목록에 노출되어 직관적인 투표 가능

### 3. 스마트 자리 배치 알고리즘 (The Secret Sauce)
모든 참가자가 투표를 완료하는 순간, 아래 우선순위에 따라 최적의 자리 배치표를 자동 생성합니다.
1. **1순위 (서로 지목)**: 서로를 선택한 남녀를 우선적으로 매칭
2. **2순위 (여성 우선)**: 서로 지목이 없을 경우, 여성이 선택한 남성 중 랜덤 매칭
3. **3순위 (전체 랜덤)**: 나머지 인원은 성별에 맞춰 무작위 배치

### 4. 익명 결과 발표
- 매칭 결과는 **전체 결과표** 형식으로 한꺼번에 공개
- 어떤 알고리즘(서로 지목 vs 랜덤 등)으로 매칭되었는지 아이콘을 제거하여 철저히 비밀 유지
- 결과 발표 순서를 섞어 매칭 근거 추측 차단

## 🛠 기술 스택
- **Backend**: Python (FastAPI), WebSocket (실시간 데이터 동기화)
- **Frontend**: Flutter (Dart), Web Browser 지원
- **Communication**: JSON-based 실시간 메시징 프로토콜

## 🏃 실행 방법

### Backend (FastAPI)
```bash
cd backend
# 가상환경 활성화 후
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### Frontend (Flutter)
```bash
cd frontend
flutter pub get
flutter run -d chrome
```
